# Legacy collection provenance

Open Apps began as the public-domain **Open Source Flutter Apps** collection:

<https://github.com/tortuvshin/open-source-flutter-apps>

The original list was published under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
It consisted primarily of public repository URLs, project names, and short
descriptions. Those facts became the seed for the structured records now kept
under `data/records/`.

The historical snapshot remains available in the Git history of
`tortuvshin/open-apps` before the Grove migration. This file keeps the
provenance and licensing boundary explicit without duplicating a second,
quickly stale catalog inside the repository.
