# Immich screenshots

This folder holds editorial screenshots used by the Open Apps detail page
for Immich.

## `timeline.png`

The timeline view, showing the Google Photos-style grouped photos with the
date rail on the left.

**Source:**
- Immich's official docs site has live screenshots at <https://immich.app/docs>.
- The Immich GitHub repository has screenshots in the README at
  <https://github.com/immich-app/immich>.

**Suggested export size:** 1280×800 or 1600×900 PNG, retina-quality.
**Suggested compression:** lossless PNG or WebP at quality 90.
**Naming convention:** `kebab-case` filenames, no spaces.
