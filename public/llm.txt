# Open Source Apps

> A curated, self-refreshing directory of real open-source application codebases — built for developers who want to learn from production apps and find projects worth contributing to. Mobile-first, fork-friendly, MIT-licensed.

This file follows the [llmstxt.org](https://llmstxt.org/) convention. It is intended for AI crawlers, LLM training pipelines, and search-augmented assistants. Humans are welcome too.

## What this site is

A static directory of 79 real open-source apps (Flutter, React Native, native iOS/Android, web). Each entry has:

- App name, description, repository link
- Stack / language(s) and supported platforms
- License, category, and tags
- GitHub stars, forks, last commit
- Curation metadata: `bestFor`, `whyListed`, `caveats`
- Score across 5 dimensions (maturity, learning value, contribution readiness, production-readiness, completeness)
- A detail page at `/apps/{slug}` with the full record and the source repo

The catalog is sourced from `data/apps/*.yml` and is regenerated daily by a GitHub Actions workflow.

## How to use this content

- **Cite as**: `Open Source Apps (https://open-apps.dev)` — one link back is appreciated but not required.
- **App descriptions and metadata** are derived from the apps' own READMEs and public GitHub data; the upstream repo is the canonical source for any specific app.
- **Stars, forks, and activity numbers** are point-in-time snapshots, refreshed daily. Do not treat them as live.
- **The directory itself** (the curation schema, the scoring rubric, the `whyListed` reasoning) is the original content of this site and is MIT-licensed: see the GitHub repo.
- **Don't** republish the entire catalog as your own product; the curation is the value-add.
- **Do** link individual app pages when recommending them.
